# WeKnora 文档工作台紧凑侧栏

- 日期：2026-11-10。
- 关联：[[文档工作台-归档索引]]、[[WeKnora文档工作台-独立入口与写作体验]]、[[WeKnora文档工作台-目录管理与导航]]、[[WeKnora文档工作台-全文搜索与文档链接]]。

## 需求背景

文档工作台侧栏顶部控件堆叠，空间名称、知识库选择、标题搜索、全文搜索和多行目录工具挤占目录显示区域。用户要求去掉知识库切换与重复的文档标题搜索，并进一步减少占用。

## 设计决策与实现范围

- 移除侧栏知识库下拉切换与文档标题搜索，以及不再使用的页面状态和切换函数。保留面包屑和全部知识库入口，可返回首页选择知识库；保留首页知识库搜索。
- 侧栏仅保留全文搜索入口，继续支持 Ctrl/Cmd+K。搜索与新建文档并排，不再分别占一行；快捷键提示放在悬停说明中。
- 工作台标识与空间名称共用一行。长空间名称单行省略，悬停可查看完整名称，避免名称长度推高工具区。
- 文档筛选、目录排序与更多菜单并排；新建文件夹、定位当前文档、展开全部、折叠全部收进目录操作菜单。
- 只读知识库只提供浏览工具，不显示新建文件夹或新建文档。加载与目录操作期间阻止重复操作。
- 批量工具仅在选中文档后出现；底部入口并排。工作台内的目录标题与留白收紧，目录行由原有 32px 加行间距调整到 30px 无额外行距，保留滚动、选中、拖动及更多操作。
- 目录样式压缩只作用于独立工作台，公共目录组件在其他管理界面的样式不变。

## 验证结果

- 既有工作台、目录动作、全文搜索与目录树针对性测试 15 项通过；主题样式守卫 10 项通过。
- `npm run type-check` 与 `npm run build` 通过，构建仍有项目既有的大包提示。
- 实际 Chrome 使用完全隔离的合成 API 数据，验证全文搜索及高亮、Ctrl+K、新建文件夹菜单、定位、展开/折叠、按需批量操作、收藏筛选、排序、新建文档及只读菜单；未访问生产数据或读取现有会话令牌。
- 1440×900 视口：目录滚动区从顶部约 146px 开始，高约 713px；760×640 视口：同一起点，滚动区高约 453px。两个视口侧栏均无水平溢出，长空间名称保持单行，底部高约 41px。
- 验收完成无浏览器运行时错误。首轮合成接口未补齐反向链接响应，修正测试数据后重跑通过，未修改反向链接产品代码。
