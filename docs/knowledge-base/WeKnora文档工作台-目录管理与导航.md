# WeKnora 文档工作台：目录管理与导航

- 日期：2026-11-09
- 状态：功能实现及本地验证已完成，未提交/发布生产版本。
- 前置：[[WeKnora文档工作台-外部内容粘贴]]。

## 需求

在独立工作台内完成文件夹新建、重命名、删除空文件夹、移动，文档批量移动与目录拖拽排序；提供目录定位、面包屑、收藏/最近访问和名称/更新时间排序。移动和删除遵循未保存保护。

## 设计决策

- 既有目录从 folder_path 推导，无法保存空目录。新增 knowledge_navigation（迁移 000905，PostgreSQL/SQLite）存显式目录、直接子项顺序及共享版本号；旧文档路径无需批量迁移。
- 新 API 的目录变更使用事务和导航行锁，带 base_revision 乐观校验。新界面不允许同名目标目录静默合并；旧重命名接口保留已公开的合并语义。
- 删除仅允许空目录及空子目录，不删除正文；移动只改所属路径，不重解析或生成正文历史。
- 全行正文/处理更新排除 folder_path，避免慢任务用旧路径将刚移动的文档放回原位。
- 文件夹及文档顺序跨浏览器共享；收藏及最近访问按用户、空间和知识库隔离，仅保存在当前浏览器，不作为授权凭据。
- 原有的权限、版本、上传等待及离开保护沿用；外部拖入或另一知识库的节点不视为可信目录操作。

## 实现与验证

后端实现位于 `internal/application/repository/knowledge_navigation.go`、`internal/application/service/knowledge_navigation.go`、`internal/handler/knowledge_navigation.go`。目录写入统一走 `PUT /knowledge-bases/:id/knowledge/navigation`，现有目录路径接口与新持久化逻辑兼容。知识库删除清理导航表，空间转移同步迁移其 tenant_id；专项回归已通过。

前端增加 `DocumentNavigationActions.vue` 操作弹窗和 `navigationModel.ts`，共享 `BrowseDocTree.vue` 可选启用目录菜单、多选、拖拽，旧浏览入口继续只读导航。独立工作台支持文件夹列表、当前位置新建、目标目录随草稿恢复、Ctrl/Cmd+K 搜索及 Ctrl/Cmd+Alt+N 新建，展开/折叠和定位。

151 项前端回归测试通过，另有 10 项主题样式约束检查通过；类型检查和生产构建通过。Go 类型、仓储、数据库完整测试及相关服务/处理器测试通过，新增共享权限、事务回滚、版本冲突、路径非法/自循环、跨库拒绝、空目录、旧接口、慢任务写回与知识库生命周期用例。真实 Chrome + PostgreSQL 验证文件夹、批量移动、拖拽进出目录、同级顺序刷新、版本冲突、未保存拦截和收藏保留；另验证当前目录原子新建文档、实际删除空目录和含文档子树重命名；无 Vue/浏览器错误，临时知识库已清理。

## 本期边界

不提供删除非空文件夹的递归删文操作，不实现多人实时协同。收藏与最近访问暂不跨设备同步。

## 注意事项

- 文件夹删除不会连带删除正文；需要先移动文档。单个文档删除继续使用原管理界面。
- 目录顺序服务端共享，收藏和最近访问仅当前浏览器。按名称/最近编辑排序不会改写手动顺序。
- 迁移 000905 仅用于本地开发服务，当前访问入口仍为 `http://localhost:8081/platform/documents`。生产尚未发布。
- 本机知识库中另补存了前三阶段记录，索引为 [[文档工作台-归档索引]]。今后完成一阶段应先更新仓库记录，再同步到该本地知识库。
