# WeKnora 文档工作台多块批量操作

- 日期：2026-11-11。
- 关联：[[文档工作台-归档索引]]、[[WeKnora文档工作台-段落块操作]]、[[WeKnora文档工作台-编辑态实时大纲]]、[[WeKnora文档工作台-自动保存与结构化正文]]。
- 状态：本地实现、验证和归档完成；本期与上一期块操作尚未提交、推送或部署。

## 需求背景

上一期支持单块复制、删除、移动和类型转换。重组多个段落及夹在其中的表格、图片和列表时，仍需逐块处理。本期沿用编辑器已有正文选区，增加连续多块的批量操作，减少整理长文的重复动作。

## 设计决策与实现范围

- 不增加独立的选择工具。鼠标或键盘选择连续正文后，按选区实际覆盖的顶层节点扩展为完整块；反向选区同样处理。结束位置恰好位于下一块边界时不包含下一块。表格内单格/多格选区仍属于同一个顶层表格，嵌套列表属于同一个顶层列表。
- 多块范围以临时装饰描边，显示实际影响的完整节点；菜单明确提示涉及的块数量，以及操作会包含这些块的全部内容。普通文本选区本身不改写；高亮、计数和选区变化不产生正文保存或撤销步骤。
- 工具栏“块操作”和已选范围内任意手柄打开整组菜单。范围外手柄继续操作自身单块。整组支持复制到下方、删除、上移一块、下移一块；组内顺序不变，上下移动与相邻的一个顶层块交换位置。
- 从已选范围内手柄拖动时捕获整组范围，使用原有编辑器内临时令牌与文档快照校验；仍只能放到顶层边界。组内边界、组首/组尾及非法嵌套位置作为无效移动处理，不生成撤销步骤。范围外手柄只拖动自身节点。
- 完整保留标题行内格式、图片资源引用/尺寸/对齐、表格单元格/列宽、列表嵌套结构等节点内容。复制使用完整片段，删除与移动使用整段原子事务，不经 HTML 或 Markdown 重建正文。
- 选中全文时可以整体复制或删除；删除全文保留合法空段落并可单步撤销，全文不能上移或下移。每次整组操作具有独立撤销步骤，继续使用既有文档容量检查、只读/组合输入/图片上传保护、自动保存与实时大纲。
- 多块菜单不提供类型转换，单块保留上一期转换规则，防止批量转换复杂节点时损失结构。正文或选区变化关闭旧菜单，避免用旧范围误操作。
- 无新接口、数据库迁移、正文存储格式或依赖。六种界面语言提供完整块数量说明；高亮仅为编辑态装饰，不进入 JSON、HTML 或 Markdown。

## 验证结果

- 块操作专项共 17 项通过，其中本期新增 7 项：部分/反向选区扩展、全文与边界处理、表格选区与文末 GapCursor、非法范围拒绝、混合节点组复制/删除/撤销重做、组内保序移动与非法落点、全文清空恢复、多块转换拒绝、高亮无持久化及撤销副作用、范围内/外手柄拖拽、只读/组合输入和容量原子拒绝。
- 最终全量前端回归 2,088 项：2,087 通过、1 项既有跳过、0 失败，包含前一期尚未提交的单块操作。类型检查、生产构建和差异空白检查通过；构建仍有既有的大包提示。
- Chrome 使用完全拦截的合成 API 数据，真实鼠标从标题拖选到列表内部，验证标题、整表和完整列表三个节点高亮及菜单计数。批量复制、删除、移动与撤销结果正确，大纲随标题复制/删除/撤销变化。范围外手柄保留单块菜单，光标变化关闭菜单并清理多块高亮。
- 鼠标触发 Chrome 原生手柄拖拽，捕获原生数据并通过 CDP 投递拖入/放下事件，验证标题/表格/列表整组移到文首，节点顺序和列宽保留，可单独撤销和重做。自动保存、刷新、重新进入编辑后结构化正文一致，装饰没有写入保存内容，选区高亮不会错误恢复到新页面。
- 在 760×640 窄窗口用原生 Enter 打开全文选区菜单，验证 7 个完整块计数、上下移动禁用、菜单未越出窗口、清空全文及撤销。检查 1440×900 桌面菜单、整组拖拽和窄窗口菜单截图；浏览器无运行时错误。
- 验收脚本对比 JSON 序列化后的结构化正文，避免 CDP 对 Vue 响应式数组的回传形态差异；重新编辑后仅保存编辑器引用，不将编辑器对象本身通过调试协议序列化。

## 已知边界与交付状态

仅支持一个连续正文选区涉及的顶层完整块，不支持不连续点选、Shift 点击手柄多选、列表项独立拖拽、嵌套缩进拖放、跨文档拖拽、批量类型转换或系统剪贴板复制块。普通文本删除/复制快捷键仍按编辑器原生选区工作；完整块批量删除/复制由块菜单执行。

操作完成后沿用单块操作的定位方式，选中结果首块；继续批量处理时需要重新选择范围。拖拽目标只接受顶层边界，全文范围没有可移动到的外部边界。未新增移动端专用选择手势；真实触屏拖拽、多浏览器、全部语言长文本及超大文档性能专项未验证。

合成接口浏览器验收不等同于生产真实账号端到端联调。本期没有提交、推送、发布或部署，线上仍是此前发布的 v1.8.8；独立后端摘要/重排工作不属于本期范围。需求、设计、实现、验证及边界同步用户指定的原本地 Obsidian 知识库，仓库保留副本与双链索引；不记录真实企业信息、登录凭据或业务正文。
