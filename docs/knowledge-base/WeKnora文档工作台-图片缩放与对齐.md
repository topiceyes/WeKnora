# WeKnora 文档工作台图片缩放与对齐

- 日期：2026-11-10。
- 关联：[[文档工作台-归档索引]]、[[WeKnora文档工作台-表格批量粘贴]]、[[WeKnora文档工作台-自动保存与结构化正文]]、[[WeKnora文档工作台-外部内容粘贴]]。

## 需求背景

图片已有上传、粘贴、拖入、说明编辑和鉴权预览，但缺少直接缩放及对齐操作。后端结构化正文已经接受图片的尺寸和对齐属性；前端编辑视图与阅读渲染没有完整使用这些字段。此次补齐图片排版，保持保存、阅读和历史恢复一致。

## 设计决策与实现范围

- 选中图片后显示缩放手柄，拖动按原图比例调整宽度。右对齐图片从左侧拖动，居中图片按中心位置调整，宽度受可用容器和 4096px 上限约束；手柄支持左右方向键每次 16px 和 Home 恢复原尺寸。
- 拖动期间只改变本地显示，不发送正文事务；松开后一次提交。Escape、指针取消或捕获丢失恢复之前显示，切换选择或图片属性变化时结束当前拖动。只读状态不接受排版写入。
- 图片工具栏支持左/中/右对齐、1–4096px 整数宽度输入及恢复原尺寸。对齐按钮提供选中样式与辅助技术状态；继续保留图片说明和删除。恢复原尺寸只清除尺寸，不改变对齐。
- 继续使用既有 `width`、`height`、`align` 字段，无数据库迁移、后端接口或结构化文档版本变化。调整宽度时清除固定高度，以原图比例显示；不提供非等比拉伸。原尺寸在较小窗口中仍受可用宽度约束。
- 图片节点保留稳定资源引用，布局变化不重新加载鉴权资源，不把预览 blob URL 写入结构。拖动提交和工具栏排版使用独立撤销步骤；只有图片格式变化时仍通过结构指纹识别并自动保存。
- 编辑器 HTML 序列化和阅读/历史 HTML 渲染共享尺寸、对齐校验与固定样式生成。图片阅读不再受旧 444px 固定上限限制，仍保持最大宽度 100%；HTML 复制可保留受支持的像素尺寸和对齐。Markdown 投影继续保存图片引用和说明，不承诺保留图片排版。
- 新增前后端共享图片格式样例，验证已有服务端白名单接受实际尺寸与对齐。六种界面语言均补齐标签与提示。

## 验证结果

- 全量前端回归 2,064 项：2,063 通过、1 项既有跳过、0 失败，包含上期未提交的表格批量粘贴回归。最终容器宽度及选中样式调整后，图片、自动保存、结构化正文、编辑器初始化、多语言和主题守卫定向复验 60 项全部通过。
- 图片测试覆盖尺寸白名单、HTML 与结构重新载入、稳定资源引用、拖动预览与单次提交、撤销/重做、取消与捕获丢失、方向键/Home、居中/右侧锚点、位置映射、容器宽度限制和只读拒绝。自动保存专项确认仅调整图片尺寸/对齐、Markdown 相同时也会保存结构并更新基线。
- Go `internal/types` 的 `TestStructuredDocument*` 测试通过，包含新增图片样例的格式验证及 Markdown 投影一致性；未修改服务端业务实现。
- Chrome 使用合成 API 和图片响应验证真实鼠标拖动、宽高比例、拖动不提前写入、取消、撤销/重做、对齐、有效/无效宽度输入、自动保存、阅读超过旧 444px 上限、历史预览、恢复旧版本、刷新及重新进入编辑、恢复原尺寸。检查桌面和较小视口的响应式尺寸，无浏览器运行时错误。
- 最终类型检查、生产构建及差异空白检查通过，构建保留项目既有的大包提示。

## 已知边界与交付状态

本期仅本地实现，尚未提交、推送或部署。上期表格批量粘贴也仍是本地修改，生产继续使用之前已发布的阅读布局版本。需求、设计和实际验证归档同时保存在仓库与用户原本地 Obsidian 知识库；独立后端摘要与重排工作未混入本期实现。

不包含裁剪、旋转、文字环绕、滤镜或图片文件编辑，不新增资源上传协议。历史和复制保真以结构化正文为准；Markdown 导出不保留像素宽度和对齐。更新后的图片排版应使用本期前端编辑，旧客户端对图片属性的保留能力不在此次验收范围。

浏览器验收使用完全拦截的合成接口和图片，不读取真实登录令牌或业务正文；不等同于真实账号服务端联调。未专项验证真实触屏、不同 Office 系统剪贴板及全部浏览器版本。
