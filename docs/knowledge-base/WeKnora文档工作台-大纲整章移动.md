# WeKnora 文档工作台大纲整章移动

- 日期：2026-11-11。

- 状态：本地实现与验证；本期未提交、推送、发布或部署，线上仍为此前发布的 v1.8.9。

## 需求背景

长文已经可以按块或连续选区重排，但移动一整章仍需要手动寻找章节结尾。实时大纲已有准确的标题定位，本期在编辑态提供整章上移/下移，降低选择不完整而拆散子标题、表格或图片的风险。

## 设计决策与实现范围

- 以正文顶层标题作为章节起点，范围延续到下一条同级或更高层级的顶层标题之前，末章延续到文末。范围包含下级标题、正文及完整容器，前言保持原位；不修改标题文字、级别或正文节点属性。
- 上移/下移只与同一父章节下同级的相邻章节交换，保留组内顺序与父子归属。父章节取之前最近的较高层级顶层标题，允许标题层级跳跃；不同父章节之间不提供移动。只有一个同级章节时不显示移动控件，首尾方向禁用。
- 引用、表格、列表等容器内的标题继续显示在大纲并可跳转，但不作为独立章节起点或边界，也不提供独立移动，避免拆开容器。
- 大纲行将跳转目标和移动按钮作为并列控件。编辑态在悬停或键盘聚焦时显示上下按钮，触摸样式下保持可见；阅读态不显示移动控件。按钮使用原生键盘交互、辅助标签和提示，明确包括下级标题与正文。六种界面语言提供翻译。
- 每个正文快照生成临时动作令牌，点击时校验当前编辑器、令牌、标题索引及当前章节关系。正文变化后旧事件拒绝执行，防止快速连续操作或旧页面事件落到新位置；不同编辑器的令牌不互通。
- 移动复用整组块事务及容量预检，表格、图片、列表、引用和行内格式完整保留，每次移动可独立撤销/重做。成功后光标定位到移动后标题开头并聚焦编辑器，方便继续输入；自动保存和实时大纲沿用既有机制。
- 只读、手动保存、图片上传、无效内容及组合输入期间拒绝相应操作；上传/可编辑状态变化更新控件，选区变化继续复用已计算的章节，不反复扫描正文。阅读器校验编辑状态后转发，已有文档与新建文档都接入大纲事件。
- 标题与章节位置、移动权限和令牌仅存在编辑器状态及组件事件中，不写入 JSON、HTML、Markdown 或本机草稿。没有新接口、数据库迁移、正文格式或依赖。

## 验证结果

- 章节/大纲专项覆盖：父子边界、相邻同级关系、层级跳跃、重名及空标题、嵌套标题禁用、完整表格/图片/引用及行内格式、前言保留、上移/下移、独立撤销重做及光标定位；旧令牌、外部编辑器、无效索引、只读、上传及组合输入拒绝；移动元信息不持久化与刷新重建。
- 新增极限节点用例：移动后若自动追加的末尾段落将超限，整次拒绝、提示容量限制，正文和撤销栈均保持原样。阅读器专项验证只向可编辑且空闲的编辑器转发，阅读/手动保存/上传/无效内容和权限不足时不转发。
- 定向复验 42 项全部通过，包含原有大纲、阅读保存、编辑器初始化及多语言键名检查。最终全量前端 2,100 项：2,099 通过、1 项既有跳过、0 失败；类型检查、生产构建和差异空白检查通过，构建保留既有大包提示。
- Chrome 使用完全拦截的合成接口和图片，真实鼠标点击及 Tab/Enter 验证整章与子章节移动，保留同名标题、前言、完整表格/图片/引用，光标聚焦和撤销正确。自动保存后返回阅读、刷新及重新编辑，章节顺序与结构一致，阅读态无移动控件。
- 新建文档和空标题章节移动、刷新后恢复已重排的本机草稿通过。检查 1440×900 悬停控件和新建页面截图、760×640 新建截图；窄窗口沿用隐藏大纲规则，工作台无水平溢出，无浏览器运行时错误。

## 已知边界与交付状态

本期只提供同一父章节下相邻同级章节的上下交换，不包含从大纲拖放、跨父章节移动、标题升降级、章节折叠、章节复制/删除或移动容器内部标题。没有同级相邻章节时不显示操作；不同级别的标题不直接互换。大纲隐藏于窄窗口或专注模式时，仍可使用已有正文块操作整理内容。

未做真实触屏、多浏览器、全部语言长文本及超大文档性能专项。节点上限测试仅验证原子拒绝，不等于超大文档交互性能验收。浏览器测试使用合成接口，不等同于生产真实账号联调。本期没有后端变更，不重复声称已修复此前标准后端发行镜像构建问题。

本期为本地功能迭代，未提交或部署。需求、设计、实现、验证和边界按约定同步用户原本地 Obsidian 知识库，仓库保留副本及双链索引；不记录企业身份、凭据、内部运维定位或业务正文。
