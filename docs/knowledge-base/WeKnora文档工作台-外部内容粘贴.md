- 前置：[[WeKnora文档工作台-自动保存与结构化正文]]。

## 需求

从网页、Word、Excel 等复制内容后保留可编辑的文字和表格，不能出现预览图片替代正文、看起来粘贴正常却无法保存的问题。

## 设计与实现

通过 ProseMirror 剪贴板插件规范化惰性 HTML，再按固定 schema 解析；不引入新依赖。支持不透明文字颜色/高亮、标准标题/列表、加粗；表格保留跨列/跨行、多段落、对齐，读取 colgroup/单元格 px、pt 宽度。

多行多列 TSV 可直接转为可编辑表格，支持引号中换行、制表符、双引号与空单元格。非矩形、不完整内容回退普通文本；纯文本快捷键和代码块保留原行为，不在已有单元格中额外创建嵌套表格。

HTML 正文与预览图片共存时优先保留正文，单独截图仍上传。复制本系统图片使用稳定的受保护资源引用；本机、临时或内嵌图片无法持久化时保留说明并提示补传。

修复列表 tight 属性未纳入后端 schema 导致保存失败，以及斜杠菜单 watcher 在 editor 引用初始化前求值的错误。

## 验证

139 项前端测试、类型检查、生产构建通过；后端结构、正文和版本测试通过。真实 8081 浏览器粘贴事件+临时知识库+PostgreSQL 验证 HTML/TSV 保存刷新保真、本机图片提示；无 Vue/浏览器运行时异常，测试知识库已清理。

## 边界

这不是 Word 文件导入；私有样式编号、浮动布局、字体、分页、图形不保证还原。表格内按选定矩形批量粘贴尚未实现。后续：[[WeKnora文档工作台-目录管理与导航]]。
