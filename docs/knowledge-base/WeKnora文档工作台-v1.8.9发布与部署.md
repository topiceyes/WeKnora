## 需求背景与范围

用户要求提交、推送、发布及部署近期块操作与复核修复。版本设为 v1.8.9，包含单块/多块正文整理、非安全 HTTP UUID 兼容及容量边界修复。独立后端摘要、标签和重排工作不纳入本次提交。

## 发布设计

按明确文件清单提交，版本文件与前端锁文件同步；使用现有 CI 与版本镜像流程，核验镜像提交信息后固定摘要部署。生产仅更新前端，保留定制后端及解析/检索辅助服务，数据库保持 906，无新增迁移。

切换前备份配置和旧前端镜像，部署脚本校验兼容、资源及健康，失败恢复旧前端。实际上线静态资源使用完全拦截的合成 API 验收，不读取生产用户令牌或业务正文。公开记录去除企业真实信息和内部运维明细，内部镜像摘要、备份定位及操作记录仅保存在私有本地笔记。

## 已知边界

无多人实时协作、嵌套或跨文档拖拽、不连续多选及多块类型转换。真实生产账号端到端、多浏览器、真实触屏和 Office 系统剪贴板验收仍为边界；合成接口不能替代这些验收。生产后端定制扩展保留，不用发行标准应用镜像覆盖。

本版可用交付为已验证的前端镜像。标准后端的 Rust 静态库与 Go 构建兼容问题尚未修复，不能把该版本描述为所有发行镜像成功；它不属于本轮前端实现，也未用失败产物替换生产后端。后端/解析源码及构建流程与上一版相同，本次没有触发 App/DocReader 源码 CI，不把上一版测试冒充本期 CI。
