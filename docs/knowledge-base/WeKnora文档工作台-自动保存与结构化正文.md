# WeKnora 文档工作台：自动保存与结构化正文

## 需求与决策

减少写作中手动保存负担，刷新可恢复未提交内容；丰富格式必须在保存、刷新和历史恢复间保真。以版本化 Tiptap JSON 为权威正文，同时兼容既有 Markdown 检索及导出。

## 实现

既有文档停止输入 1.8 秒后自动保存，最小间隔 10 秒，携带 base_version。请求期间允许继续输入，响应只推进已提交快照的基线。断网保留草稿，冲突暂停自动保存并要求明确解决。新文档首次保存前仅保存在本机，不自动创建重复文档。

恢复副本按用户、有效空间、知识库、文档、编辑会话隔离；250 毫秒防抖及页面生命周期落盘。比较正文、版本、时间和结构后只删除本次副本，不误删其他标签页的新内容。

`metadata.document = {schema_version:1,content:TiptapJSON}`；服务端校验固定节点/属性/URL 白名单后生成 `metadata.content` Markdown 投影。旧文档按需升级；旧接口改正文不能将结构化文档静默压平。详情/目录能力回执阻止旧后端静默丢格式。

新增文字高亮、颜色、四类提示块及表格合并/拆分/列宽。版本表增加 document 列（迁移 000904，PostgreSQL JSONB/SQLite TEXT），历史预览及恢复保留结构。仅改变格式也会触发修改检测和自动保存。

## 验证与经验

本阶段 128 项前端回归、类型检查、构建通过；Go 正文、版本恢复、类型及数据库迁移验证通过。临时知识库+真实 PostgreSQL+8081 Chrome 验证：颜色自动保存、鼠标拖动列宽、合并拆分、离线草稿恢复、旧 Markdown/丰富格式双向历史恢复及首次创建，测试后清理临时知识库。

修复任务列表 NodeView 装饰 DOM 被重复解析造成的循环；补齐表格 align 默认属性；避免嵌套列表/表格重复投影导致指数耗时。
