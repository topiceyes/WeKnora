# WeKnora 文档工作台：文档评论与讨论

- 日期：2026-11-10
- 阶段：独立文档工作台后续迭代——团队讨论
- 关联：[[文档工作台-归档索引]]、[[WeKnora文档工作台-目录管理与导航]]、[[WeKnora文档工作台-自动保存与结构化正文]]
- 状态：功能已实现；自动化、隔离浏览器验证和本地迁移已通过。真实用户登录会话下的浏览器端到端联调仍待验证，不能将隔离测试写成真实会话验收。

## 需求背景

在独立知识库浏览、富文本编辑、自动保存及目录管理之后，团队需要围绕文档直接提问、回复和确认处理结果，逐步补齐替代语雀的日常协作体验。讨论应独立保存，不改变正文内容、版本和 AI 索引状态。

## 设计决策

1. 评论附着于稳定的文档 ID，独立于正文 JSON、Markdown 和版本历史。现有文档在知识库间移动、知识库在空间间迁移后，讨论跟随原文档；复制出新文档时不复制原讨论。
2. 每次访问先解析持久化的文档及其所属知识库，沿用现有阅读授权与内容写入授权。查看评论需要文档阅读权限；发表评论、回复、解决/重开和删除沿用“知识库创建者或空间管理员，且具有该库 Editor 操作授权”的现有写入路由。仅有共享阅读授权的管理员不能写入。删除还必须是评论本人；API Key 的合成身份不能冒充评论作者。
3. 单层讨论与回复，根讨论支持解决/重开；解决或删除后不接受新回复。删除清除自身正文及引用，保留位置与已有回复，避免破坏上下文。
4. 选区记录原文、最多 64 字前后文和正文版本。仅在同版本、引用及上下文唯一匹配时定位，定位使用浏览器选区而不改写富文本 DOM。版本变化或匹配有歧义时保留原始引用并提示，不自动猜测新位置。创建引用评论时后端复核当前正文版本。
5. 写操作锁定文档行，复核空间/知识库绑定及移动、删除状态；相同请求 ID 与相同载荷重试不重复发帖，不同载荷复用同 ID 返回冲突。解决/删除通过评论 revision 拒绝过期修改。
6. 使用按需加载的讨论抽屉，关闭后恢复完整阅读区域；未发送内容在本页面保留，切换文档/路由前提醒，提交期间阻止离开。

## 实现范围

- 文档工作台阅读页增加“评论与讨论”入口、选区评论入口。
- 根评论、回复、解决、重开、本人删除及删除确认。
- 全部/未解决/已解决筛选、手动刷新、分页加载和失败重试。
- 纯文本显示评论，作者 ID 与名称来自服务端身份；不把评论内容作为 HTML 执行。
- 评论失败保留输入；同一载荷重试复用请求 ID。
- 每条正文最多 5000 字，引用最多 1000 字，每页 20 条讨论、每条讨论最多 100 条回复。
- 新增 `knowledge_comments` 表及 PostgreSQL/SQLite 的 `000906` 迁移；复合索引覆盖文档、父评论及时间顺序。
- 文档单条/批量删除与知识库删除清理评论；删除事务与评论创建使用同一文档行锁，避免删除并发留下新评论。
- 三个接口：`GET /knowledge/:id/comments`、`POST /knowledge/:id/comments`、`PUT /knowledge/:id/comments/:comment_id`。
- 六种语言的键集合保持一致；简体中文提供中文文案，其他语言的新增条目目前使用英语文案。

## 验证结果

- 前端针对文档工作台、浏览/编辑、知识库及语言键的 160 项测试通过，包含评论失败重试、请求去重、输入保留、迟到响应、只读阻断及未发送评论的离开提醒。
- Vue TypeScript 检查通过；前端生产构建通过，仍有项目既有包体积提示；10 项样式守卫通过。
- Go 的 types、repository、database 包完整测试通过；service、handler、router 的评论、文档写权限、目录和迁移相关回归通过。
- 真实 handler → service → SQLite 的 HTTP 测试验证持久化、服务端作者来源、回复、解决、409 冲突、引用版本校验、跨空间拒绝及正文版本不变。路由测试验证 Viewer、非创建者 Contributor、仅有 Viewer 共享权限的 Admin 不能写评论。
- 本机 Chrome 使用完全隔离的前端数据响应测试通过：评论安全展示、回复、解决/重开、本人删除占位、刷新后展示、实际 DOM 选区引用与定位、关闭面板/取消切换后保留未发送内容、正文版本变化后显示原始引用。未出现 Vue 或浏览器错误。
- 上述 Chrome 测试所有 API 均由测试脚本响应，不能视为真实登录账号与运行中后端的端到端验收。自动审批拒绝了原脚本从数据库读取会话令牌，因此未执行该读取，改用隔离浏览器验证和真实 HTTP/SQLite 测试；没有在本期为验收提取或归档任何真实令牌。
- 本地开发后端 8080 已更新并健康；前端入口仍为 `http://localhost:8081/platform/documents`。本地 PostgreSQL 实际检查为 `906 / dirty=false`，评论表已存在。

## 已知边界与后续

- 本期不提供 @成员、站内/钉钉通知、实时推送、多人同时编辑、评论编辑或跨设备评论草稿。
- 未发送文字只在当前页面内保留；刷新或关闭页面使用浏览器离开提醒，不能宣称具备评论草稿持久化。
- 引用不会跨正文版本自动重定位，也没有正文侧边批注标记；仍可阅读评论中保存的原始引文。
- 阅读者目前只能看讨论；后续若要“可评论但不可编辑正文”，需要增加独立评论权限，不能隐式扩大现有 Viewer 权限。
- 新讨论在刷新后可见；分页是偏移分页，前端合并时去重，不承诺跨用户并发插入时的快照一致性。
- 真实用户登录后的运行中系统联调尚待验证。
