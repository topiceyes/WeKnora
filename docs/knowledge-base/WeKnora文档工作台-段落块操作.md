## 需求背景

文档工作台已经具备结构化编辑、表格和图片排版及实时大纲，但重组正文仍需手工选中、剪切和粘贴，复杂节点容易选取不完整。本期增加段落块操作，便于调整文章结构，并保持已有保存、撤销和大纲行为。

## 设计决策与实现范围

- 以正文顶层节点为操作单位。正文左侧留白显示可聚焦的块手柄，点击打开操作菜单，拖动按顶层边界排序；表格、图片、整个列表、代码块和其他容器作为完整节点处理，不从容器中截取部分内容。光标位于表格或列表内部时，工具栏“块操作”作用于最外层块。
- 菜单支持“复制到下方”、删除、上移一块和下移一块。复制直接在当前文档插入完整副本，不承诺写入系统剪贴板。首块不能上移、末块不能下移；删除唯一块保留合法空段落。沿用编辑器在非文本末节点后追加可写段落的行为。
- 转换范围为正文、一级至四级标题、无序列表、有序列表和引用。来源须为段落、标题、只含段落/标题的引用，或每项仅含一个段落的简单列表；转换保留行内文字及加粗、颜色、链接等 mark。多项简单列表转换为段落/标题时逐项保留内容。
- 复杂嵌套列表、含表格等复杂内容的引用、任务列表、表格、图片、代码及其他特殊块禁用类型转换，仍可整块移动、复制或删除。同类型操作不产生空事务；复制和移动保留列表属性、图片资源引用/尺寸/对齐、表格结构及列宽。
- 拖拽采用编辑器内的临时令牌和文档快照校验，仅接受同一编辑器当前文档的操作；落点按鼠标纵坐标和块中点计算，只显示顶层插入线。拒绝跨编辑器及伪造数据，正文变化取消旧拖拽，避免旧位置误操作；内部块拖拽不显示普通文本插入光标。
- 菜单记录当前文档与位置，正文变更关闭菜单；只读、输入法组合及图片上传期间阻止相关操作。支持键盘聚焦入口、Enter 打开、Tab 操作及 Esc 关闭并回到编辑器。菜单内部可滚动，外部点击、页面滚动或窗口尺寸变化关闭；按实际尺寸约束浮层位置，避免窄窗口边框溢出。
- 每次成功操作使用一个独立撤销步骤；整次生成事务并检查既有保存上限后提交。共享原有表格粘贴容量检查：最多 20,000 节点、64 层、表格 500 行/100 列、合并跨度 100、结构化正文 JSON 2 MiB，并考虑服务端 JSON HTML 字符转义。超过限制时提示且不写入、不新增撤销步骤。
- 手柄和落点线使用 ProseMirror 装饰，不进入持久化 JSON、HTML 或 Markdown。正文变更继续走现有自动保存和实时大纲事件；无新接口、数据库迁移、正文格式或依赖。

## 验证结果

- 块操作专项 10 项通过：表格/图片/列表/代码的整块移动、复制、删除及独立撤销重做；首尾与非法落点；唯一块删除；行内格式保留及大纲同步；复杂转换禁用；表格内光标解析；装饰不持久化；跨编辑器/伪造拖拽拒绝；正文变化、取消、上传和只读保护；超容量原子拒绝。
- 最终前端全量回归 2,081 项：2,080 通过、1 项既有跳过、0 失败，包含表格粘贴、多语言键名和主题样式约束；类型检查、生产构建及差异空白检查通过。
- Chrome 使用完全拦截的合成接口验证真实页面：菜单复制/删除/移动/转换、复杂转换禁用、保留加粗、大纲变化与撤销、Esc 回到编辑器、原生 Enter 打开工具栏入口、菜单内部滚动及正文变化后关闭。
- 通过鼠标触发 Chrome 原生手柄拖拽，捕获原生拖拽数据并通过 CDP 投递拖入/放下事件，验证整张表格移动到文首、只有一条顶层落点线、保留列宽以及独立撤销/重做。合成 API 自动保存后返回阅读、刷新及重新编辑，结构化正文保持一致，手柄和落点线未进入保存内容。
- 检查 1440×900 桌面菜单及拖拽截图、760×640 窄窗口菜单截图。修复手柄位置、菜单内部滚动误关闭和窄窗口浮层边框溢出；浏览器验收无运行时错误。CDP 返回 Vue 响应式数组时以 JSON 序列化结果比较，避免把调试协议的数组显示差异误判为保存格式变化。

## 已知边界与交付状态

本期为顶层单块操作，没有列表项独立拖拽、嵌套缩进拖放、多块选择、跨文档拖拽、系统剪贴板复制块或多人实时协同。触屏用户可使用菜单上移/下移；真实触屏拖拽、全部语言长文本、多浏览器和超大文档性能专项尚未验证。大纲同步已有标题变化，但不提供从大纲拖动正文。

浏览器验收覆盖合成接口的交互与保存路径，不等同于生产真实账号端到端联调。构建仍有既有的大包提示。本期未改动生产，线上版本仍为此前发布的 v1.8.8；独立后端摘要/重排工作不属于本期范围。
