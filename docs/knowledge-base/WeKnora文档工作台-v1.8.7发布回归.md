## 背景与本次范围

用户要求全面测试最近几期功能，无问题后提交发布一个版本。候选汇总独立文档工作台、编辑器增强、自动保存/本机恢复、结构化正文、外部粘贴、目录导航、评论和全文搜索/文档链接。

本次将工作台相关修改从原基线建立隔离发布快照再测试，排除原工作区独立的重排模型配置/网关、摘要预算、自动标签和数据表摘要改动，保留它们的未提交状态。版本号统一更新 `VERSION`、前端 package 和 lockfile。

默认发布 Git 版本与容器镜像，本期测试不构成对生产服务的升级操作。生产升级需明确目标后执行备份和统一切换。实际部署位置仅保存在内部运维记录。

## 回归发现与修复

1. **标准链接保存失败**：真实 Tiptap 链接 JSON 带 `title`（默认 null），后端 schema 原先只允许 href/target/rel/class，真实保存返回 400。补齐受限的 title 属性校验与安全 HTML 转义；增加包含当前 Tiptap 全部默认链接属性的前后端共享样例，验证真实序列化 JSON 与服务端契约一致。非法 URL/属性仍拒绝。
2. **未编辑导入文档的选区评论**：parser 元数据通过 ManualMetadata 读取时会默认 version=1，而阅读器对从未在线保存的正文使用 version=0。后端改为只有在线 content 存在时使用其版本，补充导入文档原文选区版本 0 的回归测试。
3. **评论列表刷新并发**：新刷新可替换旧在途列表请求，旧响应不能覆盖新列表；列表刷新期间阻止评论状态写入，避免界面加载状态和结果更新交错。补充过期响应与在途刷新阻断测试。
4. 按项目格式和 120 列约定整理本期新增 Go 代码；根据远端静态检查补齐结构化节点的公开类型注释，重命名遮蔽内置函数的局部参数，相关类型测试通过。未修改旁支工作内容。
5. 远端 DocReader 工作流在安装 Python 阶段失败：`ubuntu-latest` 已使用 Ubuntu 26.04，固定的 Python 3.10.18 无对应发行包。将该工作流固定为 Ubuntu 24.04，保持与当前 Python 和 Playwright 依赖兼容；修复后 Python 与 Go 客户端测试均已通过。

## 真实登录、浏览器和 PostgreSQL 验收

公开注册开启的本地开发环境通过**正常注册、密码登录和切换空间 API**创建临时 Owner 与 Viewer 测试身份。凭据仅在测试进程内存中使用，不读取已有数据库会话令牌，不归档密码或令牌。所有测试库与账号、会话在结束后精确清理。

实际通过：

- 空文件夹新建/刷新保留、嵌套目录、重命名、批量移动、拖入根/目录、同级排序/刷新。
- 409 过期目录请求、拒绝删除非空目录、未保存编辑阻止目录变更；收藏刷新保留、当前目录创建文档的路径原子保存。
- 真实 Owner 可写，Viewer 只能读评论/全文搜索、不能保存正文或评论；不在该空间的同一测试用户拒绝访问。
- 评论创建/回复、解决/重开、过期 revision 返回 409；浏览器提交后的评论在刷新后仍保留。
- Tiptap 插入稳定文档链接，真实后端保存并在刷新后保留结构；跳转和 PostgreSQL 反向链接持久化正确。
- 当前已保存正文的全文命中，浏览器显示高亮片段。
- 富文本颜色、高亮、提示块、合并表格及鼠标拖动列宽；自动保存格式修改。
- 人为仅阻断隔离文档的保存接口后，富文本本机副本在刷新后可恢复，再写回真实数据库；历史抽屉正确显示富格式并双向恢复旧 Markdown/新结构；新建文档第一次保存保留结构。
- 实际 HTML/Excel 文本粘贴保留标准列表、颜色、跨行列、列宽、单元格多段落和空单元格；真实保存刷新保留。无法保存的本机图片使用可见说明并提示上传。
- 上述浏览器验收未出现 Vue/运行时错误。测试账号与库均为独立合成内容，不访问业务文档正文。

本期真实登录验收补齐前两期“只有隔离 API 界面测试”的边界；原阶段笔记保留当时状态，不回写为当时已经验收。

## 数据库升级与回滚演练

- 新数据库及既有 SQLite 的完整迁移链测试通过，目标版本 906。
- PostgreSQL 在随机 schema 的同一回滚事务内实际执行 904–906 升级、写入结构化历史/导航/评论、降级，再次升级；检查旧 Markdown 历史仍在，事务最终回滚，未改动正式表。
- down 迁移仍会删除结构化历史列、导航和评论，这是回滚演练确认的破坏性边界，不能据此宣称数据可无损降级。
- 升级前备份数据库、配置、文件和固定镜像标识；停止全部旧 app/worker，再统一切换前后端。升级后有写入时不直接回退旧镜像或执行 down，按一致时间点备份及实际写入状态恢复。

## 保留边界

- 全文搜索、反向链接限当前知识库，字面扫描有超时；没有大规模性能结论。引用显示文字不会随目标标题自动更新，稳定 ID 跳转不受影响。
- 评论没有 @通知或实时协作，选区不跨正文版本自动重定位；未发送评论仅留在当前页面。
- 本机恢复、收藏和最近访问不等于跨设备同步。Word 私有样式、复杂浮动布局不保证还原。
- 本次回归不代替未来生产业务流量、模型质量和超大文件性能观察。
