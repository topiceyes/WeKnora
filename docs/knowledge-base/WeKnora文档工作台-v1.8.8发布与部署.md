## 需求与范围

用户要求提交、推送、发布并部署最近三期编辑器优化。版本设为 v1.8.8，同时汇总自 v1.8.7 以来已上线的紧凑侧栏和阅读布局。公开说明保留通用功能、验证和升级约束，不公开企业真实信息。独立摘要与重排工作不纳入本次提交。

## 发布设计

- 前端版本文件与项目 VERSION 一致。使用现有 Frontend CI 和 Docker 镜像工作流，核对目标提交和镜像元信息后，以固定摘要部署。
- 生产只更新前端，保留既有后端扩展及解析/检索服务；数据库保持 906，无新增迁移。
- 切换前备份配置与旧前端镜像，脚本校验配置、容器和健康状态，失败自动恢复旧前端。内部定位信息仅保存本地私有运维记录。
- 使用实际上线的静态资源，所有 API/图片请求拦截为合成数据，复验三期交互；不读取生产用户令牌或真实业务正文。
