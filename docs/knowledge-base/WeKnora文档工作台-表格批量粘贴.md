# WeKnora 文档工作台表格批量粘贴

- 日期：2026-11-10。
- 关联：[[文档工作台-归档索引]]、[[WeKnora文档工作台-外部内容粘贴]]、[[WeKnora文档工作台-自动保存与结构化正文]]、[[WeKnora文档工作台-阅读布局与导航优化]]。

## 需求背景

现有编辑器已经支持表格插入、合并/拆分和列宽调整，表格外粘贴多行多列也可生成表格。但纯文本电子表格数据在已有单元格内会回退成普通文字，不能方便地批量填入。此次先补齐已有表格内的批量粘贴，图片排版、编辑态大纲另行迭代。

## 设计决策与实现范围

- 在已有表格中识别 TSV 行列数据，支持多行多列、单行多列、单列多行、尾部空单元格、引号内制表符/换行及双引号转义。公式形态的值按文字处理，不执行公式。
- 光标所在单元格或显式选中的一个单元格作为粘贴起点，向右下填入完整矩阵，不足时补行列。保留范围之外的已有内容，不生成嵌套电子表格。
- 多单元格选区要求复制矩阵尺寸一致；单个值可填满选区。其他尺寸不匹配会提示并整次拒绝，不隐式裁剪、循环填充或删除原内容。
- 目标范围包含合并单元格时提示先拆分，整次拒绝。范围之外的合并单元格保持不变；来源 HTML 中的合并布局仍可贴入未合并目标，沿用已有表格模型。
- 复用 ProseMirror 表格粘贴和结构修复逻辑，提交前先捕获事务。保留目标表头类型、已有列宽及未被来源显式覆盖的对齐；HTML 来源保留编辑器支持的文字格式。扩展表头行时新列仍为表头。
- 粘贴独立成一个撤销步骤，粘贴前后紧接的输入不并入该步骤。正常复制、纯文本快捷粘贴、代码块、图片上传及只读限制继续沿用现有行为。
- 提交前检查目标表格最多 500 行、100 列、合并跨度最多 100，以及整篇文档 20,000 节点、64 层、2 MiB 的既有保存边界。TSV 输入另有 500,000 字符上限；超限整次拒绝并提示，不把超限矩阵回退成普通文字后悄悄插入。
- 表格激活时显示简短粘贴说明，并补齐六种界面语言的提示。继续通过既有结构化正文、自动保存和 Markdown 投影持久化，无数据库或 API 变更，无新增依赖。

## 验证结果

- 全量前端回归 2,056 项：2,055 通过、1 项既有跳过、0 失败。最后补充合并跨度边界及提示映射后，编辑器粘贴、初始化、多语言和主题守卫定向复验共 46 项全部通过。
- 粘贴专项覆盖目标表头/列宽/对齐、单元格内换行、空值和公式文字、补行列、单格锚点、匹配/不匹配选区、单值填充、HTML 格式、原生复制的单元格切片与反向选区、来源/目标合并、容量及复杂度超限、纯文本粘贴、代码块、只读、一次撤销/重做及相邻输入隔离。
- Chrome 使用完全拦截的合成 API 数据验证真实 DOM 粘贴、可见提示、表头与列宽、撤销/重做、自动补行列、自动保存、返回阅读、刷新和再次进入结构化编辑。合并目标和选区不匹配时正文保持不变。无浏览器运行时错误。
- 检查 1440×900 和 760×640 截图，工作台无水平溢出，较宽表格保留编辑区内滚动。未读取已有登录令牌或业务正文；这些结果不等同于生产真实账号联调。
- 最终类型检查、生产构建和差异空白检查通过。构建仍有既有的大包提示。

## 已知边界与交付状态

本阶段结束时为本地实现。后续随 `v1.8.8` 一并提交、推送并部署前端，实际上线静态资源的合成接口交互复验通过，见 [[WeKnora文档工作台-v1.8.8发布与部署]]。仓库归档同步到用户原本地 Obsidian 知识库，不纳入独立后端摘要与重排修改。

不提供完整 Excel 功能、公式计算或电子表格文件导入；非矩形或引号不完整的普通文本仍走原有文字粘贴。目标合并单元格需先手动拆分，不自动猜测覆盖方式；不会为了适应选区而裁剪或重复多值矩阵。超出单次输入限制可分批处理，但整篇文档仍受既有保存上限约束。

真实系统剪贴板、不同版本 Excel/WPS/Sheets、真实触屏和生产账号联调未做专项验收。本期浏览器使用合成 ClipboardEvent 与合成 API，验证编辑器事件处理、提交内容和重新加载。
