# WeKnora 文档工作台阅读布局与导航优化

- 日期：2026-11-10。
- 关联：[[文档工作台-归档索引]]、[[WeKnora文档工作台-紧凑侧栏]]、[[WeKnora文档工作台-目录管理与导航]]、[[WeKnora文档工作台-全文搜索与文档链接]]。

## 需求背景

紧凑侧栏上线后，继续减少阅读页面的固定控件和重复信息，为目录标题与正文腾出空间。此次范围是目录行操作、可调侧栏、顶部阅读操作、大纲及反向链接展示。

## 设计决策与实现范围

- 在支持精确指针和悬停的设备上，独立工作台目录行的复选框及更多操作在悬停、键盘聚焦或批量选择时显示，平时释放标题宽度。触摸设备保持操作可见；其他管理界面的目录不启用此模式。
- 侧栏通过分隔条拖动调宽，也支持左右方向键每次调整 16px、Home 或双击恢复默认。宽度限制在 208–480px，并随窗口限制最大值；取消拖动恢复之前的宽度，完成后保存。
- 侧栏宽度和大纲展开偏好按用户、空间和知识库隔离，保存在浏览器本地；不保存正文，不改变权限。存储损坏或不可用时仍可继续使用。
- 阅读、评论、历史等操作移入工作台顶部，更新时间改为信息图标说明，减少正文上方重复工具栏和留白。已有正文首个一级标题与文档标题相同时，仅隐藏额外生成的标题，不删除或改写正文；标题不同时保留两者。
- 大纲不超过两个标题时默认收起，较长大纲默认展开；用户手动选择优先并在刷新后保留。原有较小窗口隐藏大纲、专注模式行为继续沿用。
- 空反向链接默认仅显示标题和数量；有引用时默认展开，保留手动展开、折叠、刷新和分页。切换文档清除上篇展开状态，忽略过期响应，刷新不覆盖当前文档的手动折叠选择。

## 验证结果

- 全量前端测试共 2,045 项：合计 2,044 通过、1 项既有跳过。首次运行两项代理测试受沙箱本地端口监听限制，允许临时回环端口后单独重跑，两项均通过；其余测试首次通过。
- 新增布局偏好测试覆盖身份/空间/知识库隔离、存储失败、宽度边界、取消拖动、窗口变化及键盘恢复；反向链接测试覆盖空状态、手动选择及切换文档后的过期响应隔离。
- 类型检查、生产构建及差异空白检查通过；构建仍有既有大包提示。
- Chrome 使用完全拦截的合成 API 数据，验证单一顶部操作栏、匹配标题去重、目录标题宽度释放、悬停/键盘聚焦/批量选择、真实鼠标拖动及刷新记忆、方向键和恢复默认、大纲自动与手动行为、反向链接展开、富文本编辑自动保存和返回阅读、只读权限下的按钮展示。无浏览器运行时错误。
- 检查 1440×900 与 760×640 截图，较小视口工作台无水平溢出。测试没有读取已有会话令牌或访问业务数据。首轮浏览器断言需计入侧栏边框，另一次合成引用 ID 不符合 UUID 契约，修正测试数据后完整重跑通过。

## 已知边界与交付状态

本期仅涉及前端，未修改后端接口、数据库或正文存储格式。布局偏好仅限当前浏览器，不跨设备同步；反向链接仍沿用现有当前知识库、结构化链接的检索范围。极窄手机、真实触屏、多语言长文本和真实登录联调未做专项验收。

本期实现与验证已在本地完成，尚未提交、推送或部署。仓库保留归档副本，并同步到用户原本地 Obsidian 知识库；公开记录不含企业真实信息、凭据或业务正文。
