# WeKnora 文档工作台：独立入口与写作体验

- 日期：2026-11-09（依据本任务记录补档）
- 状态：本机开发完成，未提交/发布生产版本。
- 前置：[[WeKnora浏览模式P1-设计与实现]]、[[WeKnora浏览模式P2-在线编辑与重新学习]]。

## 需求

替代语雀的日常阅读和写作不能依赖 AI 智能体/资料管理访问路径；原浏览入口在平台布局中被挤压，访问编辑流程繁琐。提供独立知识库阅读和写作工作台。

## 设计与实现

`/platform/documents` 提供知识库首页，`/platform/documents/:kbId?doc=:id` 提供目录、正文、大纲布局。路由不继承 AI 平台侧栏和助手面板；共享知识库沿用服务端有效权限，同一文档在管理页和工作台复用 ID、正文及历史版本。支持深链接、前进后退、专注模式。

新文档首次显式保存为 draft，团队可阅读，保存不触发 AI 索引；既有文档复用正文保存接口和版本检查。切换/离开保护未保存内容，图片上传期间阻止保存和离开。

增强现有 Tiptap：斜杠菜单、选中文字格式工具条、H1–H4、代码语言、查找替换、图片上传/粘贴/拖入。上传位置锚点随正文变化映射，持久化资源引用而非临时 blob 地址。

## 验证与边界

此前独立布局、权限、链接、切库竞态、保存失败、未保存保护和编辑器 Markdown 往返已有测试与隔离 Chrome 验证。后续完整回归覆盖这些用例；截图保存在本任务可视化目录。
