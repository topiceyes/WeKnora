# WeKnora 发布文档公开信息脱敏

- 日期：2026-11-10。
- 关联：[[文档工作台-归档索引]]、[[WeKnora文档工作台-v1.8.7生产部署]]。

## 需求与设计

用户要求去除企业真实信息后再提交公开发布说明。公开材料保留产品功能、可核实的验证结论与通用升级/回滚约束，内部定位信息仅留在用户原本地知识库的私有运维笔记。

## 实现范围

- 脱敏版本说明、部署归档、发布准备记录与本地归档约定中的真实服务器地址、内部路径、渠道标识、业务配置名称及具体运维定位材料。
- 部署公开归档不再包含定制镜像名称、内部构建标识、镜像/源码校验和、备份体积与精确切换时间。
- 相邻版本说明中重复出现的同类信息一并处理。
- Release 正文使用脱敏内容；相关归档链接指向脱敏后的提交，不再链接旧版本快照。
- 保留旧镜像回滚条件、数据库降级影响和验证边界；不修改应用代码、运行配置或生产服务。

## 验证与边界

提交前检查公开文件与拟发布正文，不含本次识别的真实内部地址、账号路径、企业邮箱、渠道标识或定制部署定位信息；检查 Markdown 差异和链接目标。与原本地知识库同步脱敏后的阶段记录，内部运维明细另存仅本地笔记。

本次处理当前文档及可编辑的 Release 正文，不改写 Git 历史，也不移动既有版本标签。旧提交及标签快照仍可能保留此前文本；本次不代表完成历史对象或外部缓存清理。
