# WeKnora 文档工作台编辑态实时大纲

- 日期：2026-11-10。
- 关联：[[文档工作台-归档索引]]、[[WeKnora文档工作台-阅读布局与导航优化]]、[[WeKnora文档工作台-表格批量粘贴]]、[[WeKnora文档工作台-图片缩放与对齐]]、[[WeKnora文档工作台-自动保存与结构化正文]]。

## 需求背景

阅读模式已有大纲，编辑时仍使用阅读页提取的标题，无法随正文变化更新，也无法正确定位编辑位置。新建页面缺少大纲。此次为长文写作补齐实时标题导航，沿用既有大纲组件和布局偏好。

## 设计决策与实现范围

- 编辑器从当前 ProseMirror 文档提取标题、级别及位置，初始化、正文变更、标题增删/改名/改级、撤销和外部内容恢复时同步更新。仅移动选区时复用已有标题列表，不重新扫描正文；不将大纲锚点写入持久化正文。
- 当前章节按光标/选区起点之前的最近标题标记，标题之前的前言不高亮章节。编辑态以光标位置为准，阅读态继续沿用滚动位置高亮。
- 点击或键盘 Enter/空格激活大纲，按当前正文位置解析标题，将光标移到标题开头、聚焦编辑器并滚动到可见区域。同名标题使用顺序与位置区分，不按标题文字搜索；导航不会修改内容、产生撤销步骤或触发正文保存。
- 已有文档进入编辑时清除旧阅读大纲，接收编辑器事件；返回阅读时重新提取阅读标题。跳转入口按当前模式分发，防止把旧阅读 DOM 的位置用于编辑。异步阅读渲染后的滚动回调在编辑模式不覆盖编辑器高亮。
- 新建页面提供同样的大纲，使用独立的本页标题与选区状态，避免残留上一篇文档标题。草稿恢复或内容重置后重新计算位置。
- 空标题保留为可定位的“空标题”，显示当前标题真实级别；标签在六种界面语言中提供翻译，当前条目增加 `aria-current`。正文中的普通 Markdown 标记和代码块文字不作为标题。
- 共用已有短文默认收起、用户手动展开偏好、专注模式和窄屏隐藏规则。仅前端调整，无 API、数据库、存储格式或依赖变更。

## 验证结果

- 全量前端回归 2,069 项：2,068 通过、1 项既有跳过、0 失败，包含前两期尚未提交的表格及图片改动。随后补充阅读器跳转路由测试和异步高亮保护，最终编辑大纲、阅读保存、工作台、多语言及主题守卫定向复验 52 项全部通过。
- 大纲专项测试覆盖初始/嵌套/空标题、标题增删改与撤销、选区变化不重发列表、同名标题与前置插入后的定位、光标聚焦、导航无正文变更及无撤销步骤、无效位置、只读/销毁状态、外部重置与清空。阅读器专项确认编辑态跳转委托给编辑器且不会触发自动保存，返回阅读后不再调用编辑器跳转。
- Chrome 使用完全拦截的合成 API 数据验证真实页面：已有长文标题修改及撤销、级别缩进、重复标题定位与编辑区滚动、当前章节、点击及键盘导航、阅读/编辑大纲切换、新建及空标题、刷新后恢复本机草稿、大纲展开偏好、专注模式和较小窗口。无浏览器运行时错误。
- 检查 1440×900 的已有/新建编辑截图和 760×640 的新建截图；较小窗口大纲按原规则隐藏，工作台无水平溢出。测试中的滚动断言针对实际位于可视区之外的标题，撤销测试按真实输入间隔隔离操作组；新建测试使用结构化标题，避免 Markdown 输入路径把测试 HTML 作为文字。
- 最终类型检查、生产构建、差异空白检查通过；构建仍有既有的大包提示。所有浏览器请求使用合成数据，未读取真实用户登录令牌或业务正文。

## 已知边界与交付状态

本阶段结束时为本地实现。后续随 `v1.8.8` 与表格粘贴、图片排版一并提交、推送并部署前端，实际上线静态资源的合成接口复验通过，见 [[WeKnora文档工作台-v1.8.8发布与部署]]。需求、设计和验证结果同步到原本地 Obsidian 知识库，仓库保留副本及双链索引；独立后端摘要/重排工作未纳入。

编辑态当前章节随光标变化，单独滚动编辑区不改变光标或高亮。大纲仅显示正文实际标题，不额外把文档标题输入框作为章节；不支持从大纲拖动重排正文。正文变更会扫描一次标题，未做超大文档专项性能测量。窄屏继续隐藏侧边大纲，未新增移动端浮层。

浏览器验收验证了合成接口上的页面交互和保存路径，不等同于生产真实账号端到端联调。真实触屏、全部语言长文本及多浏览器专项测试仍未完成。
