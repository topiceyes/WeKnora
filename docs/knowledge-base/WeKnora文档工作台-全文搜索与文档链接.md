# WeKnora 文档工作台：全文搜索与文档链接

- 日期：2026-11-10
- 关联：[[文档工作台-归档索引]]、[[WeKnora文档工作台-文档评论与讨论]]、[[WeKnora文档工作台-目录管理与导航]]、[[WeKnora文档工作台-自动保存与结构化正文]]
- 阶段：当前知识库全文搜索、编辑器文档链接及反向链接。
- 状态：已实现并完成自动化、隔离浏览器及 PostgreSQL 查询兼容性验证；真实用户登录会话下的浏览器端到端联调仍待验证。

## 需求背景

标题筛选不足以找到正文中的知识，团队文档还需要通过链接连接。独立工作台在补齐写作、目录和讨论后，本期将查找、引用与返回来源串起来。在线编辑保存的正文可能尚未重新学习，检索必须尊重当前正文，不能继续使用旧 AI 分块覆盖它。

## 设计决策

1. 范围先限定当前知识库。复用已有读权限及持久化的知识库/文档绑定，不通过搜索或引用放宽访问。搜索结果和反向链接均不列出其他知识库的内容。
2. 已在线保存的结构化正文使用可见文本投影，跨加粗、文字颜色等行内格式连续匹配，不把链接目标 URL 当正文。旧 Markdown 使用保存的文本；未在线编辑的已解析文件回退可读 text/parent_text 分块，忽略摘要等生成内容。新正文存在时不查询旧分块。
3. 使用字面、忽略大小写的匹配，百分号、下划线及正则字符均按原字符处理。每页 20 篇、文档去重、返回命中字段及最多约 180 字片段。页面仅以 Vue 文本节点和 mark 高亮，不把结果当 HTML。
4. 链接格式为 `/platform/documents/open/<文档 UUID>`，只保存稳定文档 ID，不绑定标题、目录或知识库位置。打开时请求正常文档详情 API，检查访问权限后导航到当前所属知识库。不存在和无权限使用同一提示，提供重试与返回工作台。
5. 编辑器工具栏及 `/` 菜单可调出同一文档选择器。无选区时插入文档标题链接；有选区时给原选中文字加链接。选择位置用 ProseMirror bookmark 随异步事务映射，避免上传等中间变更使插入位置漂移。正常保存、自动保存和历史结构均沿用既有链接 mark。
6. 反向链接直接读取当前已保存结构中的真实链接 mark。代码示例、纯粹出现目标 ID 的文字、外部网站上同路径的 URL 均不算引用。不创建需要同步清理的冗余引用表；删除链接或文档后，重新读取即可反映结果。
7. 正文和反向链接的普通点击通过既有工作台导航守卫；Ctrl/Cmd/Shift 点击保留浏览器行为。未保存正文或评论的离开提醒继续有效。

## 实现范围

- 工作台侧栏增加“全文搜索”入口，Ctrl/Cmd+K 打开搜索；保留原标题树筛选。
- 250 毫秒输入防抖、最近更新、正文片段高亮、键盘上下选择、加载更多、错误重试。新查询/关闭弹窗/切换知识库后忽略旧请求结果。
- 编辑器“插入文档链接”工具栏按钮和斜杠菜单项，复用搜索选择器。
- 稳定文档链接解析页，处理当前归属、重命名、目录移动、无权限/已删除及重试。
- 阅读页底部显示“引用本文的文档”，来源标题、目录、刷新和分页；普通点击走同一权限与未保存导航流程。
- 新增 `GET /knowledge-bases/:id/knowledge/document-search?query=...&offset=...` 和 `GET /knowledge/:id/backlinks?offset=...`。
- 无新数据库迁移、外部检索服务或前端依赖。本地数据库继续保持 906。
- 六语言的新增键集合一致；简体中文使用中文文案，其余新增项暂使用英语文案。

## 验证结果

- 169 项针对性前端测试通过，覆盖搜索防抖、竞态、失败/重试、分页合并、稳定链接格式、字面高亮、权限失败解析页、当前归属重定向、守卫导航和映射后的插入位置；既有保存、目录、评论、编辑和语言键测试同时通过。
- Vue TypeScript 检查、前端生产构建和 10 项样式守卫通过；构建保留既有包体积提示。
- Go types、repository、database 包完整测试通过；service、handler、router 的检索、评论、写权限、目录及迁移相关测试通过。
- Repository 测试检查当前正文优先、旧 AI 分块不误命中、导入分块回退、跨租户/跨库隔离、摘要与删除状态排除、跨格式文本、字面特殊字符、引用增删、外部链接排除、分页与取消请求。
- 真实 handler → service → SQLite HTTP 测试验证全文搜索、反向链接接口、参数拒绝及跨空间权限拒绝。稳定链接解析单元测试验证文档改归属后使用当前知识库。
- 本地 PostgreSQL 使用临时同名表与回滚事务执行实际查询结构，验证 JSONB 字段、在线正文抑制旧分块、导入分块回退和范围隔离。未改写真实业务表。
- 隔离 Chrome 测试通过：正文关键词搜索与片段高亮、选择并打开结果、实际 Tiptap 插入链接、保存刷新结构保留、跳转到目标、从反向链接返回、目标重命名/移动目录后原链接继续打开、目标删除后安全错误页。所有 API 都由合成数据响应，不能写成真实登录端到端验收。
- 本地开发后端更新并保持健康；入口 `http://localhost:8081/platform/documents`。本期无需更新数据库版本。

## 已知边界

- 全文搜索和反向链接目前均限当前知识库，不是全空间聚合搜索。稳定链接自身不绑定知识库，但实际打开仍需当前账号具有目标库权限。
- 当前采用范围内逐行读取与应用层字面匹配，每次最多 10 秒；尚无倒排索引。大知识库或大量导入分块需要后续性能测试和索引优化，不能宣称已验证大规模性能。
- 旧 Markdown 搜索其保存表示，暂不完整去除语法；未在线编辑的导入文件按单个解析文本块匹配，不保证跨两个块边界的短语可命中。尚未完成解析且无在线正文的文件不参与正文搜索。
- 反向链接只统计当前结构化正文中的标准内部链接；旧纯 Markdown/原始导入文档中的链接需在线编辑保存为结构化正文后才纳入。外部 URL、评论、历史版本和跨库来源不在本期统计范围。
- 插入时的显示文字是当时标题；目标重命名不自动改写其他文档中的链接文字，但跳转仍使用稳定 ID。复制出的新文档沿用原链接目标，不自动替换成新副本。
- 分页为偏移分页，合并时去重，不保证多人并发变动时的快照一致性；最多接受 10000 的 offset。没有语义搜索、拼音/纠错、正文内命中定位或自动更新引用标签。
- 本期延续上一期真实登录验收的待验证状态。未读取数据库会话令牌，也未通过其他方式绕过认证去完成浏览器验收。
