# 1.8.7 发布说明

本版本汇总独立文档工作台最近几期功能，便于团队直接浏览、写作、讨论和连接知识。

- 独立文档工作台，支持完整阅读区域、大纲、富文本编辑、表格、提示块、颜色及外部内容粘贴。
- 自动保存、本机恢复副本、版本历史及并发冲突保护。
- 文件夹新建、重命名、移动、删除空文件夹；批量移动、拖拽与同级排序；收藏和最近访问。
- 文档评论、回复、解决/重开、本人删除，以及正文选区引用与过期提示。
- 当前知识库内标题和正文全文搜索、片段高亮、编辑时插入稳定文档链接，以及阅读时查看反向链接。
- 发布回归修复：允许当前 Tiptap 输出的标准链接 `title` 属性；未在线编辑的导入文档使用版本 0 进行选区评论校验；评论刷新期间的操作与旧列表响应增加并发保护。

本次不纳入工作区独立的重排模型部署、摘要预算、自动标签和数据表摘要调整。

## 升级与回滚

- PostgreSQL 与 SQLite 均需执行 904–906：结构化历史正文、目录导航和评论表。历史 Markdown 文档继续可读，在线编辑保存后按需升级为结构化正文。
- 升级前备份数据库、配置及文件；停止全部旧 app/worker，再切换统一版本。前端和后端应一起升级；新前端检测后端结构化正文能力，避免误把格式正文写入旧服务。
- 保留 1.8.5/1.8.6 的知识库迁移协调协议和共享锁存储，禁止新旧进程混跑。
- 降级迁移会删除结构化历史字段、目录记录和评论。升级后产生写入时，不应直接降级或仅回退旧 app 镜像；需先停止写入，核对数据并按同一备份时间点恢复数据库及文件。
- 既有服务器为 `192.168.11.141:/opt/WeKnora`。本次默认发布 Git 版本和镜像，不因发布标签自动升级生产服务。

## 已知边界

全文搜索和反向链接限当前知识库，采用有超时的字面扫描，未验证大规模知识库性能；旧 Markdown/导入文档中的引用不自动成为反向链接。评论没有 @通知或实时推送；选区不跨正文版本自动重定位。本机草稿和收藏不跨设备同步。

完整发布回归证据与最终发布状态见 [[WeKnora文档工作台-v1.8.7发布回归]] 及仓库同名归档。
