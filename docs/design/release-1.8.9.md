# v1.8.9 · 文档块操作与稳定性修复

本版本为文档工作台增加正文结构整理能力，并修复普通 HTTP 环境及极限文档容量边界问题。

- 单块操作：顶层块手柄支持拖拽排序、复制到下方、删除和上下移动。表格、图片、列表及代码作为完整节点保留；兼容段落、标题、简单列表和引用可转换并保留行内格式。
- 连续多块操作：原生正文选区显示涉及的完整块范围和数量，可整组复制、删除、上下移动或拖拽。组内顺序及节点属性保持，全文删除可撤销恢复。
- 操作保护：独立撤销/重做、无效落点拒绝、旧文档目标失效、只读/上传/组合输入保护，继续使用现有自动保存与实时大纲。
- HTTP 兼容：拖拽令牌和评论请求 ID 使用随机字节生成 UUID v4，解决非安全 HTTP 上缺少原生 UUID 方法导致报错的问题。
- 容量边界：提交前计入编辑器自动追加的末尾段落，超限整次拒绝并保留原内容。

## 验证

发布前前端全量 2,092 项：2,091 通过、1 项既有跳过；类型检查、生产构建和差异空白检查通过。新增 224 种混合节点范围/落点组合回归。相关结构化正文、历史恢复、评论持久化/权限及文档搜索后端定向测试通过。

Chrome 合成接口验收覆盖表格粘贴、图片缩放/对齐/历史恢复、实时大纲/草稿恢复、单块和整组操作、阅读布局及保存重载；开发服务及生产构建产物在实际非安全 HTTP 上验证拖拽与评论发送。构建保留既有大包提示。

## 升级与回滚

无新增 API、正文格式、数据库迁移或依赖。生产只更新前端到经核验的固定镜像摘要，保留既有兼容后端、解析及检索服务和环境配置；数据库保持 906 正常状态。标准发行镜像不应无条件替换环境定制后端。

切换前备份 Compose 配置并保留旧前端镜像，健康及静态资源校验失败时恢复旧前端；无需回退数据库。正式 CI、发布及生产验收结果见 [[WeKnora文档工作台-v1.8.9发布与部署]]。

多块仅支持连续顶层范围，不包含嵌套拖放、不连续多选、批量类型转换或跨文档拖拽。操作后定位首块，继续整组操作需重新选择。真实账号生产端到端、真实触屏、多浏览器及 Office 系统剪贴板专项未在本期完成。
