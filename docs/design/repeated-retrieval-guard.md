# 重复知识检索保护

智能推理允许无限轮数时，已有的重复回答保护只覆盖没有工具调用的回复。模型重复搜索或读取不存在的页面不会触发该保护，可能持续消耗时间而不产生答案。

新增保护只观察 `search_knowledge`、`read_document`、`list_documents`、`query_knowledge_graph`、`wiki_search` 和 `wiki_read_page` 的已完成调用。同一调用参数和相同返回结果（包括成功状态、错误、结构化数据及图片）都已出现过时，记为一轮重复；并行批次中只要有一个新调用或新结果，该轮就不算重复。也能识别在几个已读页面之间来回切换的循环。

连续两轮重复后，通过运行时通知要求模型回答或使用不同的定向检索。通知后的下一轮仍全部重复时，在下一个轮次边界结束检索，并使用保留工具角色的现有上下文执行一次禁止工具调用的最终回答，要求明确证据缺口，不能以“继续查找”的过程描述结束。首次观察不计重复，因此同一只读调用连续四轮得到相同结果时触发最终回答。

每次工具仍真实执行，结果变化会清除连续重复计数。查询词、分页或读取范围改变也算进展。用户中途补充要求或收到协作消息会清空观察记录；任何混合工具、写入、外部 MCP、命令或其他不在名单内的操作都会清空记录，避免把写入后的重新验证误当循环。协作任务仍有未完成工作时，不把强制汇总当作成功完成，而沿用现有失败处理。

只保留最近 128 个调用结果的 SHA-256 摘要，不缓存源正文，不跳过工具执行，不记录新的查询明文。观察状态仅存在于单次活跃执行中，恢复执行重新建立观察。无需数据库迁移，也不改变已有智能体的轮数、模型或超时配置。

这是对确定重复的保护，不能判断语义相似但参数不同的检索，也不是总耗时限制。模型持续改写关键词或结果带有变化字段时，仍可能长时间运行。发布后需用真实慢问答复验：观察 `repeated_retrieval_warning`、`repeated_retrieval_stop` 日志、总耗时、工具次数及最终答案质量，再决定是否引入可配置的问答时间预算。
