# v1.8.10 · 文档阅读排版与章节整理（前端）

保存文档后的浏览页现在使用独立的阅读排版：正文 16px、1.75 倍行高、12px 段落间距，标题层级、列表、引用、表格及代码块间距统一。修复旧 Markdown 样式未指定正文行高、清零段距造成的拥挤问题；历史版本预览同步应用相同排版。保留作者插入的空段落，长代码在代码块内部滚动，支持深色主题与窄窗口。

本版同时包含 v1.8.9 之后已完成的大纲整章移动：编辑态从大纲上下移动同一父章节下相邻同级章节，连同子标题、正文、表格和图片整体调整，支持撤销、自动保存及刷新恢复。详见 [[WeKnora文档工作台-大纲整章移动]]。

## 验证与升级边界

浏览排版的相关测试 59 项、类型检查、生产构建通过。隔离 Chrome 使用合成 API 验证编辑、自动保存、返回阅读、刷新、历史预览、桌面与窄屏布局、深色主题及长代码滚动。发布最终 CI 和生产验证结果另行记录，不将合成数据验证描述为真实账号验收。

这是前端发行，无 API、依赖、正文格式或数据库迁移变更。生产仅更新已核验提交及固定摘要的 UI 镜像，部署前备份配置与旧镜像，验证失败恢复旧前端。保留环境现有兼容后端和检索/解析服务；此前标准应用镜像构建问题不属于本期修复范围。

归档见 [[WeKnora文档工作台-浏览正文排版]] 与 [[文档工作台-归档索引]]。
