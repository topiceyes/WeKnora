# v1.8.8 · 文档阅读与编辑体验

本版本改善独立文档工作台的阅读布局和长文编辑，减少固定控件占用，并补齐表格、图片和标题导航的常用操作。

- 紧凑侧栏：合并工具区域，移除重复标题搜索及侧栏知识库切换；保留全文搜索。目录操作按需显示，侧栏可拖动调宽并记忆。
- 阅读布局：操作合并到顶部，减少重复标题和留白；短文大纲及空反向链接默认收起，保留手动控制。
- 表格批量粘贴：多行多列填入已有表格，支持补行列、匹配选区和单值填充，保留表头与列宽并支持一次撤销。尺寸不匹配、目标含合并单元格或超限时提示并保留原内容。
- 图片排版：等比拖动缩放、宽度输入、左中右对齐和恢复原尺寸；支持取消、撤销/重做，阅读、历史预览及恢复使用一致排版。
- 编辑态实时大纲：标题增删、改名、改级别及撤销同步更新；点击或键盘定位光标。支持新建文档、空标题、同名标题和草稿恢复。

自动保存、恢复副本、正文版本与权限保护沿用现有机制。图片排版仅改格式时仍会保存结构化正文；大纲导航只改变选区，不写入正文。

## 升级与回滚

这是前端体验更新，无新增数据库迁移、API 或正文格式版本。后端需具备 v1.8.7 已有的结构化正文、目录和评论能力，数据库保持 906 正常状态。

生产可仅更新前端到固定镜像摘要，保留经过验证的后端及解析/检索服务。定制扩展环境应保留原有后端和配置，先核对兼容性，避免使用标准镜像覆盖环境扩展。切换前备份 Compose 配置并固定旧前端镜像，失败时恢复前端；无需回退数据库。

图片宽度和对齐以结构化正文为准，Markdown 导出不保留排版。旧客户端对这些属性的保留能力未做完整验收，编辑新排版文档应使用本版前端。

## 验证与边界

各阶段已完成自动化、类型检查、构建和隔离 Chrome 验收，覆盖表格粘贴与撤销、图片缩放/对齐/自动保存/历史恢复，以及现有和新建页面的实时大纲、草稿恢复和布局。发布提交的最终 CI 和生产验收结果记录在 [[WeKnora文档工作台-v1.8.8发布与部署]]。

未包含独立后端摘要、自动标签或重排配置改动。无多人实时协作、图片裁剪、公式计算或完整 Office 文件导入。目标合并单元格需先手动拆分，编辑大纲的当前章节随光标变化，窄屏沿用隐藏大纲规则。真实系统剪贴板、触屏及全部浏览器兼容性未做专项验收；合成接口浏览器验证不等同于生产真实账号端到端联调。
