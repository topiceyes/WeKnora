# v1.8.11 · 文档目录切换提速（前端）

文档工作台与知识库浏览目录支持标题悬停/键盘聚焦预取、短时阅读缓存及请求合并。切回刚读过的文档时直接显示正文，点击正在预取的文档复用进行中的请求；减少重复网络等待和骨架闪烁。结构化正文复用同一次 HTML 渲染，历史恢复去除重复详情请求。

缓存仅存在当前阅读器内存，有效期 15 秒，最多 8 篇、序列化总量最多 200 万字符；预取防抖 80ms，最多同时两项。保存、历史恢复、重新学习、重试、账号/租户/知识库切换及卸载时失效。晚到请求不得覆盖当前文档或回填已清理的缓存，预取失败不隐藏正式打开时的错误。

## 验证与边界

前端全量 2,109 项：2,108 通过、1 项既有跳过、0 失败；类型检查、生产构建及差异检查通过。隔离 Chrome 在相同合成文档与 400ms 详情延迟下对比：回访从 448ms 到 32ms，预取完成后打开从 441ms 到 12ms，首次未预取仍约 450ms。预取测量为悬停 650ms 后点击，单次受控数据不代表生产真实文档延迟分布。

首次未预取、缓存过期或超大文档仍需网络与渲染时间。目录尚未更新时可能复用 15 秒内的其他人旧修改，刷新可获取最新内容。本机保存立即失效。不新增后端接口、依赖、正文格式或数据库迁移。

这是前端发行，生产仅更新核验提交和固定摘要的 UI 镜像，保留现有后端、解析/检索服务和配置。部署前备份旧配置与镜像，健康及资源核验失败恢复旧前端。最终发布与生产验证结果见 [[WeKnora文档工作台-目录切换提速]]。
