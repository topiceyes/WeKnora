# 1.8.6 发布说明

本版本为智能体增加重复知识检索保护，减少相同检索反复执行但无法形成回答的情况。

- 覆盖知识库搜索、文档读取、文档列表、知识图谱及 Wiki 搜索和读取。连续两轮重复调用且结果相同后提醒模型；提醒后仍重复，在下一轮转入禁止工具调用的最终回答，基于已有证据说明结论和缺口。
- 新查询、分页、结果变化、写入和用户补充要求会重新计数，不调整现有智能体的轮数或模型配置。
- 保留检索记录和工具角色；汇总失败不会被记为成功，协作任务不会因重复检索而错误宣告完成。

本地智能体、IM 和服务层回归、定向竞态检测及 `go vet` 已通过。实现及边界见 [repeated-retrieval-guard.md](repeated-retrieval-guard.md)。

本修复识别同参数、同结果的重复，不能保证持续改写关键词的任务在固定时间内结束。真实问答的延迟和答案质量仍需上线观察。

## 升级与回滚

无需数据库迁移。在目标部署环境执行升级，先完成镜像与版本验收，再备份配置、数据库、任务存储和文件，短暂停止旧 app 及前端后切换版本。升级保留 1.8.5 的知识库迁移协调协议与共享锁存储。

升级失败时使用备份配置和固定的 1.8.5 镜像恢复服务。若升级后有业务写入或跨空间迁移，应先核对状态；不得独立恢复数据库或文件造成两者不一致。
